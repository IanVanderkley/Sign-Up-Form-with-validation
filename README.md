# Sign-Up Form with Validation

CPRG 303 – Mobile Application Development

A React Native sign-up form built with Expo and TypeScript. The form uses React Hook Form and Zod to validate five fields, show errors, and navigate to a confirmation screen after a valid submission.

This is a form-validation exercise. It does not create an account or store user information.

## Run the Project

```bash
npm install
npx expo start
```

## Technologies

- React Native and Expo
- TypeScript
- React Hook Form
- Zod
- Expo Router
